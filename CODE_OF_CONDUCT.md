# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Assume good intent.
- Critique code, not people.
- Accept constructive feedback gracefully, and give it kindly.
- No harassment, insults or personal attacks of any kind.

Report unacceptable behaviour by opening a private message to the maintainers of
the `thienta-oss-lab` organization.
